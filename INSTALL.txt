Обновление kanata: иконка, превью ссылки и лёгкая фотография

1. Замените index.html и style.css в корне проекта файлами из этого архива.
2. Скопируйте содержимое assets из архива в существующую папку assets проекта.
   Именно добавьте файлы в папку: ваш kanata-logo.svg должен остаться на месте.
3. Dockerfile и настройки AWS менять для этого обновления не нужно,
   если Dockerfile уже копирует всю папку assets в образ.
4. Старый hero.jpg можно оставить как исходник: страница использует hero.webp.
5. Запустите свой обычный процесс публикации через GitHub Actions.
6. После успешного деплоя обновите страницу Ctrl+Shift+R и проверьте иконку.
   Откройте /assets/og-image.jpg на сайте и отправьте ссылку в сохранённые
   сообщения Telegram. Вид карточки определяет мессенджер; уже отправленные
   ссылки могут сохранять старое превью.

Что изменено:
- Буква k взята непосредственно из вашего SVG, фон светлый для тёмных вкладок.
- favicon.ico: 16, 32 и 48 пикселей; SVG масштабируется без потерь.
- apple-touch-icon.png: 180 x 180.
- hero.webp: 1120 x 1399, полный кадр, 72 532 байта вместо 203 153 (-64,3%).
- og-image.jpg: 1200 x 630, логотип и полный кадр фото в полароиде.
- В head добавлены иконки, Open Graph и Twitter Card.
- У фотографии изменён src и добавлены размеры и fetchpriority.
- Название вкладки, социальные ссылки и структура HTML сохранены.
- style.css: ограничен размер логотипа на ПК; колонки могут сжиматься;
  ширина карточки учитывает высоту окна. Телефон сохраняет вертикальный вид.
- Полный кадр отображается с height: auto, без обрезки.
- CSS подключён как /style.css?v=2, чтобы обновить старую версию в кэше.

Домен пока не подключается. В метаданных используется текущий публичный ALB.
Когда появится домен и HTTPS, замените в index.html все три вхождения:
http://cloud-lab-alb-963312302.eu-north-1.elb.amazonaws.com
на https://ваш-домен (без завершающего слеша).
