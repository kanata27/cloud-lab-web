# Начни здесь

Актуальная пошаговая инструкция полного переноса: **[MIGRATION-START.md](MIGRATION-START.md)**.

1. Сохранить базы и рабочую версию.
2. Настроить Access: One-time PIN, один разрешённый email, отдельные preview/production приложения.
3. Вписать team/AUD и добавить email-секрет в оба Worker.
4. Проверить preview и импорт истории.
5. Разрешить ручной production-деплой, затем перенести финальную выгрузку AWS.
6. После проверки отключить старые AWS-ресурсы.

История SQL поставляется отдельным приватным архивом. Её нельзя коммитить. В аккаунтах ничего автоматически не переключено.
