# Заработки после полного переноса

Настройка и безопасная публикация описаны в [MIGRATION-START.md](MIGRATION-START.md). Существующие базы, ID, таблицы и записи сохраняются; создавать новые D1 или возвращать пароль AWS не нужно. Авторизация теперь общая Cloudflare Access + проверка подписанного JWT и одного email в Worker.

Сохранена логика: дата/время по Europe/Prague, CZK/EUR/USD и дополнительные валюты, свои точки, изменение/удаление через ⋯, конфликты версий, дневные графики и взвешенный почасовой доход. Инсайты соединяют заработки с посещениями по дате; посещения остаются UTC, как в прежнем API.

Курсы загружаются сервером из Frankfurter v2, провайдер ECB. Используется опубликованный курс на дату выступления; в выходной/праздник — предыдущий доступный. Для текущего дня доступен последний опубликованный курс, а не биржевая котировка каждую секунду. Исходные суммы и snapshot сохраняются с записью: история не скачет при изменении сегодняшнего курса. Смена даты запрашивает snapshot другой даты; редактирование суммы/времени того же дня использует сохранённый. Это справочная конвертация без комиссий обмена.

При недоступном сервисе и отсутствии сохранённого snapshot запись не сохраняется со случайными курсами. Значения в евро суммируют исторические эквиваленты, почасовой итог = общая сумма / общая продолжительность. Проверяй preview перед production, резервные копии держи в private/.
