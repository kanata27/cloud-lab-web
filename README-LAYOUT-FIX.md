# Обновление страницы заработков

Изменения:

- Убран крупный заголовок «Заработки». Название вкладки в навигации остаётся.
- График заработка по дням занимает всю ширину страницы.
- Сравнение точек вынесено в отдельную компактную секцию под графиком.
- Шкала графика использует округлённые шаги, например 100, 200 или 500,
  с автоматическим подбором под суммы и показатель «За час».
- Обозначение Kč выровнено над числовыми делениями шкалы.
- Убрано «(+1 день)» из времени в таблице выступлений. Продолжительность
  и расчёт заработка за час сохраняются. В форме остаётся флажок
  «Окончание на следующий день» для выступлений через полночь.

## Установка

1. Распакуй архив в корень проекта в текущей ветке feature/….
2. Замени три файла в statistics-panel и файл tests/browser/earnings.spec.mjs.
3. Сделай commit и push. Проверки и публикация preview запустятся автоматически.
4. Дождись зелёных check и deploy у push-запуска в Actions → Cloudflare site.
5. Обнови https://preview.kanata27.com/stat-panel/earnings.

В архиве нет конфигурации Wrangler, секретов, миграций или файлов backend.
Для этого обновления не требуется менять настройки Cloudflare.

## Зачем две базы D1

kanata-earnings-preview обслуживает preview.kanata27.com и хранит тестовые
записи. kanata-earnings-production обслуживает основной сайт kanata27.com
и хранит реальные записи. Каждое окружение подключено к своей базе.
Две базы нужны для отделения экспериментов, редактирования и удаления
тестовых данных от настоящего учёта. Записи между базами автоматически
не копируются. Реальные выступления после публикации следует вносить
через основной сайт.

## Проверено

Прошли сборка, 14 автоматических тестов и все 8 браузерных сценариев.
Проверены ширины 320, 390, 1000 и 1440 пикселей, светлая и тёмная темы,
расположение секций, округлённая шкала при нулевых и разных суммах,
переключение показателя графика и сохранение окончания на следующий день
при редактировании выступления.
