# Инсайты и фильтры заработков

Новая страница: `/stat-panel/insights`. Ссылка добавлена в панели «Посещения» и «Заработки».

Пять карточек показывают заработок в CZK, средний доход за час, просмотры, переходы в YouTube и Instagram. Доход за час рассчитывается из общей суммы и общего времени выступлений, а не как среднее арифметическое ставок отдельных записей. Уже сохранённые суммы в разных валютах используются с их историческими курсами.

Зелёные столбцы показывают заработок, синяя линия — просмотры за те же календарные даты. Шкалы независимы и начинаются с нуля. «Недели» суммируют дни с понедельника по воскресенье; первая и последняя недели включают только дни внутри выбранного диапазона. Переключение не меняет итоговые карточки и не отправляет повторные запросы.

Диапазон до года загружается автоматически частями не более 90 дней из существующего AWS `/stats`. Заработки читаются из существующего `/earnings-api/entries`; отдельная база и миграции не нужны. При ошибке любого сервиса график скрывается, чтобы недоступные данные не выглядели как нули. Тестовые цифры из макетов в приложение не встроены.

В «Заработки» перенесены оформление и поведение «Дата / Период» из «Посещений», включая календарь, быстрые периоды и кнопку «Показать». Возврат из даты в период восстанавливает прежний диапазон. Календарь используется обеими страницами из общего модуля.

## Границы дат

Существующий AWS API отдаёт ежедневные посещения в UTC. Заработки хранятся по дате выступления в Праге. «Инсайты» соединяют эти отчёты по сохранённой календарной дате; они не пересчитывают UTC-просмотры в пражские сутки и не привязывают переходы к конкретному выступлению. Для точного единого часового пояса требуется изменение AWS-агрегации, исходников которой в этом ZIP нет. Выбор «Сегодня» в «Инсайтах» соответствует UTC, в «Заработках» — Праге, как в исходных отчётах.

## Проверка и публикация

`npm ci`, `npm run build`, `npm test`, `npm run test:browser`.

Архив содержит проект целиком. Распаковать поверх рабочего проекта, проверить diff и закоммитить новые файлы. Обычные команды публикации preview/production сохраняются. AWS-ресурсы, D1-данные, параметры авторизации и workflow не изменены.
