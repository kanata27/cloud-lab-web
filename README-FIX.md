# Исправление теста и автодеплой preview

Распакуй этот архив в корень своей рабочей копии, сохраняя папки. В нём только изменённые файлы. Конфигурация баз, фото, исходники AWS и текущие записи не заменяются.

В текущем проекте workflow называется `.github/workflows/deploy.yml`. Новый `ci.yml` создавать не нужно: два одновременно активных workflow могут запустить два деплоя.

После коммита и `git push` в ветку `feature/earningsPage` или другую `feature/*` GitHub запускает проверки, затем публикует её на https://preview.kanata27.com. Pull Request не нужен. Вложенные имена, например `feature/ui/earnings`, тоже поддерживаются. Создание пустой ветки без нового коммита может не запускать событие push — отправь коммит с изменениями.

Все feature-ветки используют один preview-домен и одну preview-базу. На домене будет последняя успешно опубликованная ветка. Деплои выполняются по одному; перед публикацией проверяется, что ветка не обновилась за время тестов. Повторный workflow старого коммита не публикует устаревшую версию.

Основной сайт публикуется по прежним условиям: вручную из `main` с target `production` либо push в `main`, если уже включена переменная `CLOUDFLARE_PRODUCTION_ENABLED=true`. Feature-ветка не публикуется в production даже при ошибочном ручном выборе этого target. Pull Request запускает проверки без деплоя.

## Что исправлено

Тест вводил первую сумму до окончания запроса создания точки и закрытия модального окна. На медленном runner окно ещё блокировало форму, поэтому CZK оставалось 0, а сумма составляла только 95 Kč из евро/долларов. Теперь тест ждёт закрытия окна, проверяет выбранную точку и все три введённые суммы. Ответ создания точки специально задерживается на 150 мс, чтобы проверять этот случай. Ожидаемый итог остался 315 Kč — расчёт не подгонялся под ошибку.

После устранения этой гонки обнаружился второй сбой: скрытая подпись в широкой таблице увеличивала ширину всей страницы на телефоне. Её положение теперь ограничено контейнером таблицы. Таблица прокручивается внутри своего блока; вся страница не растягивается. Проверяются ширины 320, 390 и 1440 пикселей.

## Перед первым автодеплоем

В переданном RAR `database_id` обеих баз всё ещё состоит из нулей. Если ты ещё не заполнил их в своей ветке, сначала создай D1 и впиши настоящий ID тестовой базы в `wrangler.preview.jsonc`. У токена Cloudflare должно быть разрешение D1 → Edit. Полная инструкция — `EARNINGS-SETUP.md`.

Если GitHub остановит публикацию из-за правил окружения, открой **Settings → Environments → preview → Deployment branches and tags** и разреши `feature/*`. При вложенных именах добавь правило подходящей глубины, например `feature/*/*`. Production сохраняет собственные ограничения. Проверки должны завершиться успешно перед деплоем.

## Проверка

Прошли 13 автоматических проверок Node.js и все 7 браузерных сценариев на собранных статических файлах с теми же заголовками CSP. API в браузерных тестах подменяется; реальная логика Worker проверена отдельно с SQLite. Условия workflow проверены официальным вычислителем выражений GitHub Actions на 9 сценариях: push feature/main, ручной запуск и Pull Request. Публикация в аккаунт Cloudflare не выполнялась.

Курсы по-прежнему загружаются сервером из Frankfurter/ECB: на дату выступления, а для сегодняшних записей — последний опубликованный курс с кэшем до часа. Курс и исходные суммы фиксируются при сохранении. Фиксированные числа используются только в тестах.
