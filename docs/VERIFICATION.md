## Границы проверки

В рабочем контейнере недоступно перечисление сетевых интерфейсов. Для локального Wrangler использован временный адаптер, возвращающий loopback 127.0.0.1; в проект он не входит. Браузерные тесты использовали доступный Chromium с указанным executable path. На обычном GitHub runner тесты устанавливают Chromium через Playwright и запускают Wrangler без адаптера.

В браузерных тестах AWS-ответы подменяются, а внешняя загрузка шрифтов выключена. Это проверка клиента и маршрутизации, не аудит Lambda. Твой настоящий пароль не запрашивался, успешный реальный вход из Cloudflare проверишь на preview по START-HERE.md.

Доступа к Cloudflare/AWS Console и исходникам Lambda нет: DNS, IAM, настройки DynamoDB, развёртывание в аккаунте и удаление старых ресурсов не выполнялись. Новую схему таблиц или пароль не придумывали. Финальная проверка действующего сайта выполняется workflow smoke и ручным входом после публикации.
